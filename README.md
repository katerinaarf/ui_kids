### KidsUI - Java & Android Studio Project 
This project is a User Interface for Kids developed using Java and Android Studio for a Human-Computer Interaction assignment at AUEB. The interface is designed to be simple and intuitive, allowing children to interact with various features of an Android device in a fun and safe way.

# Human Computer Interaction - AUEB Assignment


## Features:
Make Calls: Easy-to-use interface for making phone calls.
Save Contacts: Save and manage contacts easily.
Take Photos: Use the camera to take pictures.
View Photos: Simple gallery to view saved pictures.
Play Games: Fun and engaging mini-games.
Watch YouTube Kids: Access child-friendly videos on YouTube Kids.
Draw and Paint: Built-in drawing application for creative expression.

## Technologies:
Java: Core programming language.
Android Studio: Integrated development environment (IDE) used to build the application.

## Purpose:
The goal of this project is to create a child-friendly user interface while exploring concepts of Human-Computer Interaction (HCI). This application helps children interact with technology in a safe and engaging way.
